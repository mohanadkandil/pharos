# Pharos

Build a little Alexandria, one block at a time.

An isometric, Nile-side voxel builder that runs entirely in the browser.
Sun-baked limestone, turquoise water, palm crowns, souq clutter and the
occasional grand monument — click a cell, pick an asset, and a city
assembles itself under your cursor.

## Status

Work in progress — the engine and asset set are being built in the open.
This README will grow into full documentation once the first playable
build lands.

## Running

Any static file server works:

```bash
python3 -m http.server 8000
```

then open <http://localhost:8000>.
